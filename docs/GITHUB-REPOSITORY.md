# GitHub repository metadata · Metadatos del repositorio

## 🇬🇧 English

### Repository name

`design-frontier`

### Short description

Source-available design orchestration and validation for consistent frontends built by AI coding agents. Free for noncommercial use.

### Extended description

Design Frontier turns product requirements, brand decisions, interface archetypes and layer-scoped references into a versioned frontend contract. It generates semantic tokens, app and landing specifications, agent instructions, implementation exports and validation reports so Claude Code, Codex, Gemini, Cursor and GitHub Copilot build within the same visual system instead of inventing a new one on every page. Source-available under the PolyForm Noncommercial License; commercial use requires a separate license.
