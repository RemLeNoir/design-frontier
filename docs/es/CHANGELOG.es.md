# Registro de cambios

## 1.1.0 - 2026-07-17

- Añadidas recetas ejecutables por capa a las referencias del catálogo.
- Añadidos contratos de capa compuestos a los documentos de diseño generados.
- Añadida una inspección más profunda del repositorio para rutas, inventario de componentes y riesgos de estilo.
- Añadido `audit` con puertas de publicación y un informe de auditoría de diseño persistente.
- Ampliados los metadatos del repositorio, el `.gitignore` y la documentación de publicación.
- Añadidos tests para el comportamiento de recetas, inspección y auditoría.


## 1.0.0

- Versión canónica estable de formato 2.
- Veinte referencias revisadas y doce arquetipos de producto.
- Quince capas de composición acotadas y reglas de compatibilidad.
- Entrevista adaptativa e inspección del repositorio más rica.
- Tokens semánticos estilo DTCG con reconocimiento de tema y sobrescrituras profundas.
- Exportadores de CSS, TypeScript y Tailwind.
- Adaptadores para Claude Code, Codex, Gemini CLI, Cursor y GitHub Copilot.
- Bloques de instrucción gestionados no destructivos.
- Carga de plugins locales y de npm para referencias, arquetipos, compatibilidad, exportadores y validadores.
- Migración de formato 1 con copias de seguridad con marca temporal.
- Validación entre archivos para decisiones, referencias, tokens, adaptadores y artefactos.
- Manifiesto de artefactos generados con SHA-256 y comando `diff`.
- Escaneo de deriva de tokens de frontend y comando `lint`.
- JSON Schemas públicos y fixtures de conformidad.
- Documentación de gobernanza, seguridad, migración, plugins, adaptadores y validación.
- Flujo de trabajo de smoke-test de paquete limpio.
