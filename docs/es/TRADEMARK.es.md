# Política de marca y nombre

El nombre **«Design Frontier»**, los nombres de comando `design-frontier` y `df`,
el logotipo del proyecto y el logotipo tipográfico (en conjunto, las «Marcas»)
son propiedad del titular del copyright del proyecto. **No** están licenciados
bajo la [PolyForm Noncommercial License](LICENSE.es.md).

La licencia de software te permite usar, modificar y distribuir el código con
fines no comerciales. **No** te concede derechos sobre las Marcas.

## Puedes hacer, sin pedir permiso

- Afirmar, con veracidad, que tu proyecto «usa Design Frontier» o está
  «construido con Design Frontier».
- Referirte al proyecto por su nombre en artículos, charlas, documentación y
  tutoriales.
- Mantener las Marcas intactas en copias sin modificar del proyecto.

## No puedes hacer, sin permiso por escrito

- Usar «Design Frontier» (o un nombre confusamente similar) como nombre de tu
  propio producto, servicio, fork, paquete o empresa.
- Publicar una versión modificada, fork o redistribución bajo las Marcas de modo
  que sugiera que es el proyecto oficial o que cuenta con su respaldo.
- Usar el logotipo o el logotipo tipográfico para dar a entender asociación,
  patrocinio o respaldo.
- Registrar las Marcas, o nombres o dominios confusamente similares, como
  propios.

## Forks y derivados

Eres libre de hacer un fork del código para uso no comercial, pero un fork
público debe usar un **nombre distinto** y dejar claro que no es el proyecto
oficial Design Frontier. Por favor, elimina o reemplaza el logotipo y el
logotipo tipográfico en un fork renombrado.

## Solicitar permiso

Para cualquier uso de las Marcas más allá de lo permitido arriba —incluyendo uso
comercial, co-branding o denominación— contacta con: info@apferrer.com

Esta política protege a los usuarios frente a la confusión sobre qué es oficial.
No restringe las libertades que la licencia de software ya concede sobre el
código en sí.
