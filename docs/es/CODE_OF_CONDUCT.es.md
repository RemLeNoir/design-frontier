# Código de conducta

Design Frontier es un proyecto técnico abierto. Participa con honestidad, respeto y sin acoso. Debate sobre el trabajo, no sobre el valor de quien lo propone.

Las conductas inaceptables incluyen los ataques personales, el lenguaje discriminatorio, la intimidación, la interrupción deliberada y la publicación de información privada.

Los mantenedores pueden editar, ocultar o eliminar contribuciones que incumplan estas reglas y pueden restringir la participación cuando sea necesario. Los informes pueden enviarse de forma privada a través del contacto de seguridad documentado en `SECURITY.md` hasta que exista una dirección específica para asuntos de conducta.
