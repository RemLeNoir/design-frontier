# Validation codes

Codes are stable identifiers for automation. Messages may improve between compatible releases.

## Project and canonical files

| Code | Meaning |
|---|---|
| `DES001` | Missing project configuration |
| `DES002` | Invalid project configuration |
| `DES003` | Missing reference composition |
| `DES004` | Missing tokens |
| `DES005` | Legacy format requires migration |
| `DES006` | Missing decisions |
| `DES007` | Missing unresolved-decision file |
| `DES012` | Invalid reference file |
| `DES013` | Unknown reference |
| `DES014` | Reference assigned to unsupported layer |
| `DES017` | Generated references do not match project composition |
| `DES032` | Invalid token JSON |
| `DES033` | Required semantic token group missing |
| `DES034` | Token leaf lacks `$type` |
| `DES035` | Token file differs from configured generation |
| `DES042` | Required generated artifact or adapter missing |
| `DES065` | Configured logo is missing |
| `DES071` | Unknown archetype |
| `DES072` | Invalid decisions file |
| `DES073` | Decisions differ from composition |
| `DES074` | Open unresolved decisions remain |
| `DES075` | Invalid unresolved-decision file |

## Integrity and extensions

| Code | Meaning |
|---|---|
| `DES082` | Manifest file missing |
| `DES083` | Generated artifact hash changed |
| `DES084` | Invalid manifest |
| `DES085` | Artifacts were generated by another package version |
| `DES090` | Plugin or catalog loading failed |
| `DES091` | Plugin validator failed |
| `DES101` | Raw color outside canonical tokens |
| `DES102` | Literal dimension outside canonical tokens |

## Catalog

`CAT001` through `CAT011` cover minimum stable size, evidence, freshness, unknown IDs, unsupported archetype assignments, and compatibility data.

Plugin validators should use their own uppercase prefix.
